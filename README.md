INATROAGENTMZ Agendamento de Exames de Condução

Este projecto consiste num website completo e responsivo para agendamento de exames de condução e gestão de escolas de condução em Moçambique.  
Inclui um formulário de agendamento, listagem de escolas registadas, dashboard analítico e um design totalmente optimizado para desktop e dispositivos móveis.

Funcionalidades Principais

1. Agendamento de Exames
- Agendamento de exames teóricos, práticos ou ambos  
- Validação de dados no navegador  
- Seleção de escola, data e categoria  
- Confirmação imediata após submissão

2. Registo e Visualização de Escolas
- Lista de escolas de condução registadas  
- Informações básicas (localização, contacto e número de alunos)

3. Dashboard Analítico (Simulado)
- Estatísticas de agendamentos diários, semanais e mensais  
- Taxas de aprovação  
- Distribuição de escolas por província

4. Design Responsivo
- Totalmente funcional em smartphones, tablets e computadores  
- Menu mobile optimizado

5. Navegação Inteligente
- Scroll suave entre secções  
- Botões de acesso rápido  
- Layout profissional e organizado

Como Executar o Projecto Localmente

1. Baixar o projecto
Faça download ou clone o repositório:


git clone https://github.com/seu-usuario/autoescolamz.git


2. Abrir no navegador
Basta abrir o ficheiro `index.html` em qualquer navegador moderno:
- Chrome  
- Firefox  
- Edge  
- Opera  

Não é necessário servidor.

Testar com Servidor Local (Opcional)

VS Code + Live Server
1. Abrir o projecto no VS Code  
2. Instalar a extensão **Live Server**  
3. Executar "Open with Live Server"
